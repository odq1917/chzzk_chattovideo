# 치지직 채팅 영상 만들기 (ChzzkChatToVideo)

[치지직 / SOOP VOD 채팅 내역](https://chzzkchatexport.vercel.app/)을 **생방송 채팅처럼 올라가는 투명 배경 영상**으로 만들어 주는 Windows 프로그램입니다.
만든 영상은 프리미어 프로 같은 편집 프로그램에서 원본 영상 위에 그대로 얹어 쓸 수 있어요.

## 다운로드

[Releases](https://github.com/odq1917/chzzk_chattovideo/releases)에서 받으세요.

- `ChzzkChatToVideo-x.y.z-portable.exe` — 설치 없이 바로 실행
- `ChzzkChatToVideo-x.y.z-setup.exe` — 설치형

> 서명되지 않은 프로그램이라 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있어요. 「추가 정보 → 실행」을 누르면 됩니다.

## 사용법

1. **채팅 불러오기** — 채팅 추출기에서 저장한 **CSV 파일**을 열거나(창에 끌어다 놓아도 됨), 「클립보드 복사」한 내용을 붙여넣으세요.
   - `[00:10:05] <닉네임> 내용` 형식, 앞의 `{1}` VOD 번호나 `[영상 후원 1,000원]` 후원 라벨도 읽어요.
2. **화면** — 영상 크기(예: 1920×1080)와 채팅 상자의 위치·크기를 정하세요. 미리보기에서 상자를 끌어 옮기고, 오른쪽 아래 모서리로 크기를 바꿀 수 있어요.
3. **글자 / 닉네임** — 글꼴(설치된 글꼴 목록에서 고르기), 크기, 글자 간격, 외곽선, 글자 그림자, 닉네임 색(10색 팔레트 자동 배정 · 한 가지 색 · 숨김)을 정하세요.
4. **배경** — 채팅마다 글자 길이에 맞춰 늘어나는 **말풍선**(기본) / 채팅 상자 전체에 하나 / 없음. 말풍선은 색·불투명도·둥글기(알약 모양까지)·상하좌우 여백·간격·그림자를 조절할 수 있어요.
5. **이모티콘** — 채팅 속 `{:d_41:}` 같은 치지직 이모티콘을 그림으로 바꿔요.
   - 채팅 추출기에서 이모티콘 주소를 함께 내보낸 CSV/복사 내용(추출기 v1.9.0 이상)이면 **자동으로 받아서** 등록해요.
   - 직접 등록: 목록에서 이름마다 「지정」, 또는 파일 이름이 이모티콘 이름인 이미지(예: `d_41.gif`)가 든 폴더를 통째로 등록. 한 번 등록하면 다음에도 그대로 써요.
   - 쓰인 이모티콘을 많이 쓰인 순으로 보여주고 미등록을 표시해요. 미등록은 원문 그대로 / 회색 `[이름]` / 지우기 중에서 골라요.
   - 크기(글자 대비 배율), 좌우 간격, 위아래 위치 조절. GIF·APNG·WebP 움직이는 이모티콘도 돼요.
6. **연출** — 스크롤 속도, 새 채팅 서서히 나타나기, 채팅 상자 위쪽에서 서서히 사라지기.
7. **미리보기** — ▶로 재생하며 확인하세요. 미리보기와 결과 영상은 같은 방식으로 그려져서 보이는 그대로 나와요.
   - **참고 화면**: 스크린샷이나 원본 영상을 불러와(창에 끌어다 놓아도 됨) 채팅 뒤에 깔고, 실제로 합성했을 때 크기감을 확인할 수 있어요. 영상이면 채팅 시계에 맞춰 같이 재생되고, 「영상 0초 = 채팅 ○○:○○:○○」로 시작 위치를 맞출 수 있어요. 결과 영상에는 들어가지 않아요.
   - **배율**: 화면에 맞춤 / 실제 크기(영상 1픽셀 = 모니터 1픽셀) / 150% / 200%.
   - **크게 보기**: 전체 화면으로 보기. Space 재생/정지, ←/→ 5초 이동, 더블클릭 또는 Esc로 나가기.
8. **영상 만들기** — 시간 범위, FPS, 형식, 출력 크기를 고르고 「영상 만들기」. 진행률·속도·남은 시간이 표시되고, 취소할 수 있어요.

### 연출 방식

- VOD 채팅 기록은 1초 단위라서, **같은 1초에 올라온 채팅 N개는 그 1초를 N등분해서 차례로** 올라와요 (4개면 0.25초 간격).
- 새 채팅은 아래에서 부드럽게 밀고 올라오고, 채팅이 몰리면 밀어 올리는 거리가 합쳐져 끊김 없이 이어져요.
- 움직이는 이모티콘은 **영상 전체 시간 기준으로 한 사이클**을 돌아요. 누가 언제 쳤든 같은 이모티콘은 같은 동작이고, 영상을 중간부터 잘라 뽑아도 어긋나지 않아요.
- 왼쪽 설정 칸은 단계마다 접고 펼 수 있고, 설정은 자동 저장돼요.

## 출력 형식

| 형식 | 배경 | 비고 |
|---|---|---|
| WebM (VP9) | 투명 | 가장 작음. **프리미어 프로에서는 투명이 안 보이고 검은 배경이 돼요** (실제 확인). OBS·웹 등 WebM 투명을 읽는 곳용 |
| MOV (QuickTime Animation) | 투명 | **프리미어용 추천.** 큼 |
| MOV (ProRes 4444) | 투명 | 매우 큼 |
| MP4 (H.264) | 그린스크린 | 작음. 크로마키로 빼서 사용 |

### 출력 크기

- **영상 전체 크기** — 설정한 영상 크기(예: 1920×1080) 안의 지정 위치에 채팅이 들어간 영상. 편집 프로그램에 그대로 얹으면 위치가 맞아요.
- **채팅 상자만** — 채팅 상자 크기(예: 440×720)만큼의 영상. 위치는 편집 프로그램에서 직접 잡고, 대신 **훨씬 빠르고 작아요.** 몇 시간짜리 VOD라면 이쪽을 권장합니다.

### 용량 · 시간 참고 (VOD 1시간 기준)

실제 치지직 방송 채팅(말풍선·이모티콘 포함) 2분을 1920×1080 / 채팅 상자 440×720, 30fps로 렌더링해서 1시간으로 환산한 값입니다(개발 PC 기준). 실제 속도는 PC 성능과 채팅 밀도에 따라 달라요. 채팅이 없는 구간은 훨씬 빨리 지나갑니다.

| 형식 · 출력 크기 | 용량 / 1시간 | 렌더링 시간 / 1시간 |
|---|---|---|
| QuickTime Animation · 채팅 상자만 | 약 3.8GB | 약 1.5분 |
| QuickTime Animation · 전체 크기 | 약 4.5GB | 약 4.5분 |
| ProRes 4444 · 채팅 상자만 | 약 29GB | 약 5분 |
| ProRes 4444 · 전체 크기 | 약 32GB | 약 30분 |
| WebM · 채팅 상자만 | 수백 MB | 약 4분 (채팅이 매우 빽빽한 예시 기준) |

- WebM은 구간을 CPU 코어 수만큼(최대 8개) 나눠 동시에 인코딩한 뒤 이어붙여요. (저장 위치에 `.partN` 임시 파일이 잠깐 생겼다가 지워져요)

> 프리미어 프로에서는 **QuickTime Animation**을 권장합니다. **채팅 상자만**으로 뽑으면 더 작고 빨라요(위치는 프리미어에서 잡기).
> 긴 VOD는 시작/끝 시간을 나눠서 여러 파일로 뽑아도 됩니다.

## 직접 빌드하기

```bash
npm install
npm start          # 개발 모드 실행
npm run dist       # Windows exe 만들기 (dist/)
```

- `v`로 시작하는 태그를 올리면 GitHub Actions가 Windows에서 exe를 만들고, 실제로 영상을 렌더링해 보는 점검을 거친 뒤 Release에 올립니다.
- 점검 모드: `electron . --smoke-test=out.webm --smoke-format=webm --smoke-seconds=10 --smoke-output=box`

## 구성

- `src/main.js` — Electron 메인: 창, 파일 대화상자
- `src/encoder.js` — ffmpeg 인코딩
- `src/emojiStore.js` — 이모티콘 보관함 (앱 데이터 폴더)
- `src/ui/` — 화면, 미리보기, 렌더링 루프
- `src/ui/shared/renderer.js` — 타이밍(1초 N등분), 줄바꿈, 닉네임 색, 말풍선, 이모티콘, 스크롤 연출, 그리기
- `src/ui/shared/parse.js` — CSV / 텍스트 읽기 (이모티콘 주소 포함)
- `src/ui/emoji.js` — 이모티콘 이미지 풀기(움직이는 이모티콘 프레임), 이모티콘 목록
- 인코딩은 [ffmpeg-static](https://github.com/eugeneware/ffmpeg-static)에 포함된 ffmpeg를 사용합니다.
