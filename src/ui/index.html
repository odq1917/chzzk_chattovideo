치지직 채팅 영상 만들기

1. 채팅 불러오기

채팅 추출기에서 저장한 CSV 파일, 또는 「클립보드 복사」한 내용을 넣으세요.

불러온 채팅 없음

2. 화면

미리보기에서 채팅 상자를 끌어 옮기고, 오른쪽 아래 모서리를 끌어 크기를 바꿀 수 있어요.

3. 글자

글꼴

크기 · 간격 · 색

4. 닉네임

팔레트 (각 칸을 눌러 색을 바꿀 수 있어요. 같은 닉네임은 항상 같은 색)

5. 배경

말풍선

둥글기를 말풍선 높이의 절반 이상으로 하면 알약 모양이 돼요. 위·아래 여백은 줄 높이(글자 크기 × 줄 높이 배수) 바깥쪽 기준이라, 글자를 위아래로 옮기려면 위·아래 여백을 서로 다르게 주세요.

상자 배경

공통

6. 이모티콘

불러온 채팅에 이모티콘이 없어요.

크기 · 위치

채팅 추출기(v1.9.0 이상)로 저장한 치지직 채팅에는 이모티콘 주소가 같이 들어 있어서 자동으로 받아요. 직접 등록하려면 목록의 「지정」을 누르거나, 파일 이름이 이모티콘 이름인 이미지(예: d_41.gif)가 든 폴더를 등록하세요. 한 번 등록하면 다음에도 그대로 써요. 움직이는 이모티콘은 영상 전체 시간 기준으로 돌아서, 누가 언제 쳤든 같은 이모티콘은 같이 움직여요.
